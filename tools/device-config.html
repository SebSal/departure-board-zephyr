Device configuration

Fills the device's settings over its USB shell, so nothing has to be typed by hand. Talks to the board with Web Serial straight from the browser; no server, no flashing. Station ids come from the stop picker.

  • Needs a browser with Web Serial: Chrome, Edge, Opera or Firefox 151+, over https:// or file://.
  • A snap or flatpak browser cannot see /dev/ttyACM*: Ubuntu's Firefox and Chromium snaps have no serial-port interface, so the port chooser stays empty even though the device is there. Use an unconfined build.
  • The shell only answers while the device is awake. Hold the button for 3 s at boot to enter config mode - or press Config mode + reset here, which does it without touching the board. It stays there for advanced/config_timeout seconds (default 300) and then sleeps.
  • A device that boots with nobody reading its USB output goes mute for good: the peripheral's tx fifo fills and never drains, so the shell answers nothing even though it still executes what you send. Connect first, then Reset device, so this page is attached across the boot. Straight after flashing it can also still be in the ROM bootloader, which looks the same and is cured the same way.
  • Reset pulses RTS, which the ESP32-C6 turns into a chip reset. USB re-enumerates, so the page reconnects on its own — but the device boots into its normal cycle.
  • Config mode + reset stores advanced/enter_config first, which the firmware reads once on boot and deletes as it reads it. So the device comes up in config mode exactly once and is back to normal after the boot that follows — there is nothing to switch off. A pack below the low-battery cutoff still wins and sleeps instead.
  • Only fields you fill in are sent. Values are quoted and non-ASCII bytes are sent as \xNN escapes, because the shell drops raw bytes above 127.
